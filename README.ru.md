# YRSL Launcher — подготовка первой сборки

Статус: подготовлен CI для сборки оригинального Amethyst. Сборка на macOS ещё
не запускалась, IPA не получен. Это исходная база проекта, а не завершённый YRSL Launcher.
Название приложения и интерфейс пока оригинальные: по заданию сначала нужна успешная
сборка оригинала, затем брендинг и последовательные изменения с проверкой компиляции.

Основа: https://github.com/AngelAuraMC/Amethyst-iOS
Исследованный commit: `f98c4133c72d39e06ceac42b57cc4477c52105fc`.
Исходные README.md, LICENSE, авторство и уведомления сохранены.

## Первая сборка с Windows

Репозиторий: https://github.com/YRSL64/Amethyst-iOS
Рабочая ветка: `yrsl-launcher`; изменения предлагаются в Pull Request к `main`.

Workflow запускается при push в `yrsl-launcher` и событиях Pull Request.
Если GitHub показывает, что Actions отключены в форке, откройте Actions и нажмите
кнопку разрешения workflows. Ручной workflow_dispatch появляется после попадания
workflow в основную ветку. Не требуется локальный Xcode на Windows.

При успехе скачайте artifact `amethyst-baseline-ipa`, распакуйте ZIP и найдите IPA.
При ошибке скачайте `baseline-diagnostics`: в нём build.log и данные зависимостей.
Наличие workflow в репозитории ещё не означает успешную компиляцию.

Workflow использует `macos-15`, Homebrew, JDK 8 для сборки Java-кода лаунчера
и отдельные iOS arm64 runtimes 8/17/21/25 для приложения. Системный JDK 21 для macOS
не заменяет iOS runtime. Верхний Makefile запускается последовательно, нативная
сборка использует три задания. IPA проверяется до загрузки artifact.
Загружаемые runtimes зависят от сервера upstream; вычисленные SHA256 сохраняются
для аудита, но не являются заранее доверенными контрольными суммами.

Исходные workflows сохранены как `.yml.upstream`: они используют частные runners
`J316sAP`/`MacStadium` и не должны занимать очередь Actions в вашем форке.
Новый workflow не использует Apple-сертификат: результат требует переподписи.

## Что уже есть в исходной базе

По коду и README upstream, без подтверждения на вашем телефоне:

- локальные аккаунты, Microsoft Login и Demo Mode;
- выбор версий, профили игры, скачивание ресурсов и журнал ошибок;
- Java 21 и другие runtimes;
- настройки памяти, разрешения, графики и сенсорного управления;
- установщики Fabric/Forge и модпаков.

Локальный профиль не предоставляет лицензию или доступ к online-mode серверам.
Для игры используйте принадлежащий вам контент и разрешённые серверы.
Microsoft-вход и demo сохраняют штатную логику upstream; они отдельно не тестировались.

## Установка с Windows и подпись

После получения настоящего IPA используйте AltStore Classic/AltServer:
https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows

Установите зависимости Apple по этой инструкции, затем AltServer, подключите iPhone
по USB, подтвердите доверие и установите AltStore через AltServer. Включите Developer
Mode в настройках iPhone, если требуется. Откройте IPA через добавление приложения
в AltStore Classic. Учётные данные вводите в официальном инструменте установки.

Бесплатная подпись действует 7 дней, требует обновления и имеет ограничения
числа активных приложений/App IDs; AltStore тоже занимает слот приложения.
Источник: https://faq.altstore.io/altstore-classic/your-altstore
Подпись development-профилем и доступность нужных entitlements проверяются
на устройстве. Ad-hoc подпись ldid в CI не заменяет Apple provisioning profile.
Установка IPA сама по себе JIT не включает.

## JIT и iOS 27

Совместимый способ JIT на iOS 27 пока НЕ подтверждён. На настоящем iPhone нужно
проверить подпись, подключение отладчика, Java 21, рендерер и запуск 1.21.4.
В исходниках есть UniversalJIT26.js и интеграция StikDebug. Название скрипта
не доказывает совместимость с iOS 27.

Официальная отправная точка настройки pairing-файла с Windows и StikDebug/StikJIT:
https://faq.altstore.io/altstore-classic/enabling-jit
Проверяйте поддержку именно вашей версии iOS в текущей документации инструмента.
При сообщении Amethyst о legacy script следуйте его инструкции: назначьте
UniversalJIT26.js из Documents приложения через Assign Script в StikDebug.
Это путь для проверки, а не обещание работающего JIT на iOS 27.
Pairing-файл держите локально, не добавляйте в GitHub.

В entitlements.sideload.xml есть get-task-allow, расширенное адресное пространство,
увеличенный лимит памяти и приватные ключи. Обычная подпись бесплатным Apple ID
не гарантирует их сохранение или действие. Мы их не добавляем сверх upstream.
TrollStore/jailbreak на указанной связке устройств и ОС не проверены.
Публичный runner GitHub только компилирует приложение; JIT на телефоне он не включает.

## Дальнейшая проверка

После зелёной baseline-сборки: установка → запуск приложения → Microsoft/demo →
проверка JIT → выбор Java 21 → скачивание 1.21.4 → проверка доступных рендереров →
загрузка мира → сохранение/перезапуск → сенсорное управление → Java-сервер.
Сначала сохраняйте резервную копию миров. Проверьте FPS, память и нагрев.
Fabric проверяется отдельно для выбранной версии и набора модов.

Затем последовательно внедряются брендинг YRSL, новый тёмный интерфейс,
улучшения локальных профилей/demo, настройки и отдельный менеджер серверов.
Каждый этап требует новой успешной сборки. Эти изменения пока не выполнены.
